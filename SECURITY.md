# Security

English | [简体中文](SECURITY.zh-CN.md)

## Reporting a vulnerability

Please do not disclose security-sensitive details, credentials, private logs, raw provider sessions, or exploit material in public issues. Use GitHub's private vulnerability-reporting channel for this repository when available, or contact the repository owner privately through an established channel.

## Portal boundary

This documentation portal must not collect or publish secrets, private component source, private commit identities, private development evidence, or raw execution transcripts. Architecture documentation may describe security boundaries without weakening them.

## Responsible handling

Reports should contain the minimum information needed to reproduce and assess impact. Do not attempt destructive testing, unauthorized provider execution, remote-resource mutation, or access to systems you do not own.
