## Documentation boundary

The portal owns stable public philosophy and system mental models. Concrete schemas, lifecycle states, protocol fields, and implementation facts belong to CLH, CLE, CLF, or CLT. Current private development state belongs to the separate Program Coordination repository.

A useful rule is: **philosophy may lead implementation; ontology should follow implementation evidence.**
