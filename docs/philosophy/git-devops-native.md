# Git/DevOps-native development control

English | [简体中文](git-devops-native.zh-CN.md)

Git and DevOps practices give development control durable reviewable artifacts: repository identity, change history, validation signals, policy, receipts, and handoff material. They do not make every commit, CI result, or agent message authoritative by themselves.

Coordination Loop uses these familiar controls to make state explicit, evidence inspectable, and side effects bounded. It is repository-addressed but may coordinate a set of repositories and resources when their identities and authority are explicit.
