# Non-goals

English | [简体中文](non-goals.zh-CN.md)

This portal and product family are not:

- a monorepo, source mirror, or Git-submodule wrapper for the four products;
- a generic multi-agent runtime, generic workflow engine, model router, or coding-agent launcher;
- FleetSplice, a God-mode agent UI, or Program Coordination;
- a claim that every component source repository is public or production-ready;
- a place for secrets, private logs, credentials, raw provider sessions, or private development evidence.

The portal is a public front door. It does not add a fifth runtime product or runtime dependency role.
