# 仓库模型与逻辑组合

[English](repository-model.md) | 简体中文

四个产品保持为独立仓库。门户对它们进行链接和说明；不会嵌套其文件、导入其源码树或使用 Git 子模块。

跨产品组合是逻辑性的。未来被接受的发行集可以记录需要共同使用的精确组件身份、版本、提交身份、工件/协议身份和兼容性集身份。[发行集示例](../../compatibility/release-set.example.yaml)刻意标记为非权威，并使用占位符而非私有提交身份。

这一机制记录的是**精确产品状态的逻辑组合，而不是文件系统嵌套**。兼容性通过生产者拥有的序列化合同、工件和一致性证据来验证，而不是通过子模块指针或嵌入另一仓库的源码检出。

独立的 Program Coordination 仓库保留开发记忆、架构、路线图、决策和交接。它不会在运行时被导入。这个公开门户同样没有运行时依赖角色。
