# Coordination Loop Portal Governance

English | [简体中文](AGENTS.zh-CN.md)

This repository is the public project portal for Coordination Loop. It is not runtime product source.

- Do not add Git submodules or `.gitmodules`.
- Do not copy, import, vendor, or nest CLH/CLE/CLF/CLT implementations here.
- Preserve bilingual parity for every human-facing Markdown change; run `python scripts/check_bilingual_docs.py`.
- Verify exact current product boundaries and component visibility before changing architecture or maturity claims.
- Do not let provider-specific behavior silently become core architecture.
- Agent output is evidence, never authoritative state merely because it exists.
- Preserve foreign and local work; do not reset, overwrite, delete, or clean ambiguous content.
- Keep one writer per worktree/branch and use focused commits.
- Remote-resource authority is explicit and Goal-scoped. Do not create, delete, transfer, archive, fork, or change visibility of a remote resource without the corresponding authorization.

The product remains exactly `CLH + CLE + CLF + CLT`; this portal is the front door, not a fifth product.
